# 30–120 秒复刻与校准记录

本轮继续独立的 `recreation/` 工程，保留前 30 秒细调内容，把预览时间轴扩展到 120 秒。最终导出按用户要求为 **1920×1080、60 fps**。30–120 秒片段为 90 秒、5400 帧；0–120 秒为 120 秒、7200 帧。

## 观察与校准

- 覆盖 30–120 秒的 360 张四分之一秒抽帧用于检查所有场景；对切点、扫描带和曲线另读取实际源帧时间。
- 原片约 29.97 fps。以秒而非原项目的暂定 BPM 驱动场景；60 fps 输出每一帧取 `frame / 60`，关键帧之间连续求值。源片中离散的故障事件按最近源帧采样，保留它们的短促停顿。
- 14 种静态图标按参考剪影描为矢量路径，保存原尺寸及参考边界。曲线段另外记录 50 个源帧的前景矢量，扫描带记录 94 个源帧的覆盖范围。运行时没有播放参考片或使用其整帧纹理。
- 文字按可见字形及原尺寸核对，重点校准维度、警告、时间旅行、联合、猫的注释、Configuration 和管理系统标题的位置与边界。保留 DIMENTION、Clam 等原片拼写。
- 前景图形、文本、遮罩在 Canvas 中生成纹理，经 Three.js / WebGL2 / GLSL 合成。全段用绝对时间计算，无动画累计状态。

## 导出与复查

```sh
cd recreation
npm run build
npm run render -- --fps 60 --start-frame 1800 --frames 5400 --out output/continuation-30-120-1080p60.mp4
node tools/compare-continuation.mjs
# 需要重新生成全长版本时：
npm run render -- --fps 60 --frames 1800 --out output/opening-0-30-1080p60.mp4
node tools/assemble-120.mjs
node tools/verify-exports.mjs
```

对照视频左侧为参考、右侧为复刻，左右各保持 16:9。两侧使用相同的绝对时间，不对参考进行光流补帧。配乐从 `media/soundtrack.m4a` 的第 30 秒截到第 120 秒，不变速；全长版本使用其第 0–120 秒。原视频无音轨，因此起点继续采用已有零偏移设定。

开发服务器运行时，`node tools/check-continuation.mjs` 保存 63 个代表时刻截图并检查浏览器错误、120 秒定位范围及乱序重绘一致性；`node tools/check-playback.mjs` 检查音频定位与 120 秒自动停止。导出器比较全部源像素、效果参数和着色器源帧号，仅在最终画面相同时复用 WebGL 像素。`node tools/check-frame-cache.mjs` 对比复用结果与强制重绘；实际变化的图形与故障仍逐帧计算。最终通过 FFprobe 核对分辨率、帧率、帧数、时长和音轨，并抽查编码后的画面。原有 0–30 秒的 21 个定位/重绘检查点也保留并通过。

## 还原程度

已实现此范围的全部场景、主要文字、图标、平面旋转/缩放、遮罩、进度与故障切换。仍有差异的是原素材的数字噪声、扫描撕裂纹理、运动模糊，以及部分次要文字和复杂变形轨迹；这是程序复刻，不声明像素一致。120 秒之后的内容尚未实现。

## 本次交付验收结果

- `continuation-30-120-1080p60.mp4`：1920×1080，60 fps，5400 帧，视频/音频均为 90.000 秒。
- `recreation-0-120-1080p60.mp4`：1920×1080，60 fps，7200 帧，视频/音频均为 120.000 秒；前 30 秒同样重新渲染为 60 fps。
- `continuation-30-120-comparison-60fps.mp4`：1920×588，60 fps，5400 帧，90 秒；左右画面各 960×540，顶部 48 像素为标签。
- 三份文件均为 H.264 / yuv420p + AAC / 44.1 kHz / 双声道，已实际解码核对帧数。
- 63 个新增场景检查点、21 个原有检查点、18 组复用/重绘比较、音频播放/定位/终止检查通过。
- 从成片抽查 11 个关键时刻；画幅、方向、主体与浏览器渲染一致。该检查验证导出完整性，不是与参考片像素一致的证明。
- 配乐在片段与全长文件共 8 个采样位置对照原 `.m4a`，包括 30 秒拼接前后；检测到的偏移均为 0 ms（8 kHz 检查采样率），相关性 0.994–0.9999。详细结果见 `output/audio-verification.json`，规格见 `output/export-verification.json`。
