# 145–170 秒精修与播放器界面

本轮继续修改同一公开站点，只更新网页与源代码；没有导出 MP4。原配乐保持 `media/soundtrack.m4a`，时长与零偏移不变。导出接口仍默认 60 fps。

参考视频为 1920×1080、30000/1001 fps。对照按实际 PTS 就近取帧，快速闪烁不能使用向上取整的截图代替。测量覆盖 145–170.81 秒的 774 个源帧，其中 639 个时刻含独立排版、几何或色彩数据。开发缓存及参考截图均不进入站点。

- 保留黑色观影风格，整理标题、播放器、章节和配乐信息。
- 时间显示改为 `mm:ss.mmm`；进度条显示已播放位置。
- 章节在当前页面跳转，显示当前章节并保留可复制的时间链接。
- 支持空格播放/暂停与左右方向键跳转 5 秒；聚焦原生控件时保留其键盘行为。
