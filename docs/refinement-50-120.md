# 50–120 秒精修记录

本轮针对 50 秒以后构图、轮廓与播放节奏的差异，继续使用 Canvas → Three.js / WebGL / GLSL 的程序实现。原参考视频不参与网页运行，配乐继续使用 `media/soundtrack.m4a`。公开站点已更新为版本 2，并保留公开访问。

## 已修正

- 旅行/联合：横条上下边、年份指针轨迹、下划线厚度、红蓝曝光转换与空白闪场；文字不再贯穿原片的短暂空白帧。
- 状态/情绪/执行：边框出现时刻、STIMULATION 位置、进度格数、三角形独立淡入、Happy 的切换和高亮退出、执行文字放缩与选择条运动。
- 盾牌/TRAPPED：曝光、盾牌与钥匙孔位置、斜排字阵、白帧，统一到最近实际源帧，修正切点附近的错场。
- 对象/营养：茄子和番茄的轮廓、填充、下落与退场；杯子/气泡/猫的位移，保留原片 `ANTIOXIDENTS` 拼写。
- 存在/配置：白场中扫描带的覆盖范围；符号描边/填充；移除把整个白底误认成扫描带的效果。
- 表盘/王冠/绳结：环的旋转、压扁、层级、节点与交叉线轨迹；百分比时序、黄色闪场。
- 解锁/放大镜：完整开锁轮廓，放大镜与环的实际运动，底部注释的退出。
- 管理/分区/隔离：管理卡片从左边展开，齿轮独立运动，卡片收窄和退出；门卡遮罩、禁止符号与单卡的出入；末尾小卡片的首次放大。
- 修复背景缓存改名后内存场景仍引用旧索引的问题。

## 校准方式与结果

测量 49.4–120 秒的 **2117 个源帧**，记录孤立的前景轮廓、横条边界、箭头透明度、曝光、卡片边界和通道偏移。主要文字由字体单独绘制，短暂转场的剪影保留前景轮廓。轮廓保存为 Path2D 矢量，颜色场用渐变和矩形生成，运行时不加载视频或整帧截图。使用 `tools/measure-continuation-motion.py` 后运行 `tools/refine-ui-motion.py` 可重新生成这些数据；OpenCV、numpy、FFmpeg 只在开发测量时使用。

精修前后各取 50–119.75 秒的 **280 个四分之一秒检查点**，对照最近的实际参考 PTS。在 320×180、5×5 高斯平滑后的 RGB 平均绝对差为 **13.120 → 4.863**（0–255 范围），下降 **62.9%**。这是同条件下修改前后的回归指标，不是准确率，也不是逐像素一致的证明。

## 检查结果

63 个 30–120 秒场景检查点、21 个前 30 秒检查点、18 组帧复用/强制重绘比较，以及音频定位、播放和 120 秒自动停止检查通过。21.8 秒在一次并行检查中出现了 PNG 不一致，单独复查及完整检查重跑均未再出现；前 30 秒实现未作改动。最终导出的规格与音频同步另见 `output/export-verification.json` 和 `output/audio-verification.json`。

## 播放、导出与限制

网页仍以配乐作为播放时钟，支持 0–120 秒定位、播放/暂停和 120 秒自动停止。公开地址：

https://world-execute-recreation-20260930.miociallo0721.chatgpt.site

导出规格保留 1920×1080、60 fps。49.4–120 秒重新逐帧渲染；前段使用已有 60 fps 导出，拼接后用原 `.m4a` 重新生成整段音轨。0–120 秒包含 7200 帧，30–120 秒包含 5400 帧。原片约 29.97 fps：对象矢量和离散故障保持源帧，连续参数仍按每个输出时间计算，配乐不变速。

```sh
cd recreation
npm run build
# 整段重新生成（不依赖既有前段文件）：
npm run render -- --fps 60 --start-frame 1800 --frames 5400 --out output/continuation-30-120-1080p60.mp4
node tools/assemble-120.mjs
node tools/compare-continuation.mjs
node tools/verify-exports.mjs
python tools/verify-audio.py
```

数字噪声的随机纹理、扫描撕裂、运动模糊、TRAPPED 字阵的细部和部分文字的重影仍有可见差异。特别是 69 秒彩色噪声、70–72 秒故障与 102 秒重影，不能据上述平均数判断为完全还原。此记录属于前 120 秒精修版本。后续已补完 120 秒至片尾，见 [完整片尾记录](completion-120-236.md)。

## 最终成片验收

- 30–120 秒：1920×1080、60 fps、5400 帧、90.000 秒。
- 0–120 秒：1920×1080、60 fps、7200 帧、120.000 秒。
- 左右对照：1920×588、60 fps、5400 帧、90.000 秒；两侧画面各 960×540。
- 三份视频的画面与音轨均从 0.000 秒开始；修复了完整视频拼接时 AAC 预留包使视频起点后移约 23 ms 的问题。
- 实际解码核对帧数与规格；8 个配乐采样点检测到的偏移均为 0 ms。
- 8 个编码画面按帧编号对照独立浏览器截图，RGB 平均绝对差为 0.915–2.264（压缩与颜色转换差异），场景位置、方向和内容一致。记录见 `output/refined-frame-verification.json`。
